## Project Description

**Project Name**: NettoChiaro

**Project Type**: Public web calculator prototype

**Description**: Converts annual gross salary into estimated annual and average monthly net pay for a standard 2025 private employee resident in Milan. It demonstrates the complete reasoning from RAL to net through source-backed formulas and explicit simplifications.

**Key Features**:
- RAL and 12/13/14-payment input with deterministic calculation
- Reconciled contributions, IRPEF, deductions, surtaxes, credits, and net output
- Explanation of what, why, formula, source, and limitation for every applied rule

**Users/Roles**: Anonymous visitors; deployment operator through EasyPanel only

**Integrations**: Private GitHub repository and EasyPanel deployment; no runtime API

**Constraints**: Italian UI, tax year 2025, one simplified standard case, no persistence or runtime AI, Docker deployment to EasyPanel, delivery through a live URL
